# Cassino.px777 🎰
Bet-px-777

## Descrição
Sistema completo de jogos de cassino com múltiplos jogos populares implementados em Python.

## Jogos Disponíveis

### 🎰 Roleta
- Apostas em números específicos (paga 35:1)
- Apostas em cores (vermelho/preto) (paga 2:1)
- Apostas em par/ímpar (paga 2:1)
- Números de 0 a 36

### 🃏 Blackjack (21)
- Jogo clássico de 21
- Jogador vs Dealer
- Compre cartas ou pare
- Dealer compra até 17 pontos

### 🎰 Caça-níqueis (Slot Machine)
- 3 rolos com símbolos especiais
- Jackpot com 3 símbolos iguais
- Multiplicadores de até 50x
- Símbolos: 🍒 🍋 🍊 🍇 ⭐ 💎 7️⃣

### 🎲 Dados (Craps)
- Adivinhe a soma de 2 dados
- Acerto exato paga 10:1
- Diferença de 1 paga 2:1
- Soma varia de 2 a 12

## Como Jogar

### Instalação
```bash
# Clone o repositório
git clone https://github.com/brasileiroalberto2-cmd/Cassino.px777.git
cd Cassino.px777

# Não é necessário instalar dependências (usa apenas bibliotecas padrão)
```

### Executar o Jogo
```bash
python main.py
```

### Uso
1. Digite seu saldo inicial (padrão: R$ 1000)
2. Escolha um jogo no menu
3. Faça suas apostas
4. Acompanhe seu saldo e histórico
5. Divirta-se jogando!
